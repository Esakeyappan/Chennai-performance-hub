# Chennai Performance Hub

A simple responsive website created as a digital-marketing practice project.

## Included
- Responsive landing page
- Services section
- About section
- SEO-friendly title, description and keywords
- Insights/blog section
- Lead-generation form
- Browser-local lead storage for practice
- No backend required

## Publish for free
### GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `styles.css`, and `script.js`.
3. Go to Settings → Pages.
4. Choose Deploy from a branch → main → root.
5. Save and open the generated Pages URL.
